# 简介
- 通过行号边栏操作实现多行选中 —— 连续多选、非连续多选、追加多选、切换选中状态、记忆选中状态。

# 安装方式
## 通过 Obsidian 社区插件市场
- 即将上线。

## 手动安装
1. 在最新发布版本页面下载 main.js 和 manifest.json。
2. 将两个文件复制至库目录下 /.obsidian/plugins/line-multi-select/。
3. 重启 Obsidian，在「设置 > 第三方插件」中启用本插件。

# 功能特性
1. 单击任意行号即可选中整行。
2. Ctrl/Cmd + 单击：切换选中状态，将单行加入或移出当前选中范围。
3. Shift + 单击：选中两行之间的连续内容。
4. 按住LMB拖动：快速选中一整块连续行。
5. 使用方法2 追加选区时，会追加到被记忆的选区中。
